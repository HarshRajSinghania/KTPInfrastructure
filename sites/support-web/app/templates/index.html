Server commands

typed in game chat · the short list you'll actually use
1 · start.ktp <password>or .scrim / .12man / .draft — no password
2 · confirm.confirmone player from each team
3 · ready.ready6 per team (default)
4 · first half.statuslive — clock runs
5 · halftime.readymap reloads, sides swap, ready up again
6 · second half.statuscombined total decides it
7 · tied?.ktpOT <password>overtime — fresh tech budget
.pause and .tac are disabled — .tech is the only pause. Each team gets 300 seconds of tech time for the whole match, not per half: spend 4:00 in the first half and you start the second with 1:00. Overtime gets its own fresh budget. To unpause, the pausing team says .resume and the other team confirms with .go.
Starting a match .ktp · .scrim · .12man · .draft
.ktp <password>Official league match. The season password comes from your captain or the admins.
.ktpOT <password> or .ktpotContinue a tied official match into overtime — 5-minute rounds.
.scrimScrim — a menu asks 20 or 15 minutes. No password.
.12man12-man — a menu asks Standard or 1.3 Community (queue ID). No password.
.draft · .draftOT for OTDraft match. No password.
.confirmPre-start confirmation — one player from each team, then ready-up begins.
.cancelCancel a match that hasn't gone live yet. Once live, only an admin can reset it.
Ready & status .ready · .status
.ready or .rdyReady up. The half goes live when enough players on both teams are ready — 6 per team by default.
.notreadyTake your ready back.
.statusWhere the match stands: phase, ready counts, score.
Pauses .tech only — see the budget rule above
.tech or .technicalTechnical pause: 5-second countdown, then the game freezes. Charges your team's match budget while live. Spectators can't call it.
.resumePausing team asks to unpause.
.goOther team confirms — short countdown, play resumes.
If a player drops mid-round the server can auto-pause on its own. It resumes the same way: .resume from the affected team, .go from the other.
Practice & between matches .prac · .changemap

.nade or .grenadeHands you a grenade. Practice mode only.
.nc or .noclipToggle noclip. Practice mode only.
.endprac or .endpracticeBack to normal play.
.changemapMap menu — anyone can use it, blocked while a match is running.

Before you report — quick fixes
Kicked for a cvar?

The server enforces competitive cvar limits. The kick message names the cvar — set it back to an allowed value in console and reconnect. A plain bounds kick is not a ban and not a cheating accusation. Policy: ac.ktpdod.com.

Map or file download failing?

Custom maps download from our mirror on connect. Retry once; if one map fails every time, report it here with the exact map name — a file missing from the mirror is a real fault we can fix quickly.

Looking for a demo?

Every match is recorded — demos live at fastdl.ktpdod.com/demos.

In-game admin commands

flags come from users.ini · grants go live at the nightly restart
Match recovery & server control admin flags required
.forceresetRCON (l) — clears ALL match state after a confirm step. The recovery hammer for a wedged or abandoned match.
.h2restart or .restarthalfRCON (l) — restart a live 2nd half to 0–0, keeping 1st-half scores. Confirm step; live 2nd half only, not OT.
.setstate <args>RCON (l) — rebuild match state (scores, half) after a crash or bad reset. Takes arguments; retype within 10s to confirm.
.kickKICK (c) — menu-based kick with audit logging. Immunity (a) honored.
.ban · .unbanBAN (d) — menu-based ban / ban-record removal, audited.
.restart · .quitRCON (l) — restart / shut down the server process, audited. Never during a live match without agreement.
.hltvrestartRCON (l) — restart this server's paired HLTV instance (recording recovers on the next match event).
.changemap needs no flag — any player can use it between matches, so it lives in the public reference. Full command inventory, aliases and permission notes: design/COMMANDS.md in KTPInfrastructure.
